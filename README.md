<h2>‧₊˚ ┊ About this Project</h2>
A simple Java-based Hotel Management System developed to demonstrate fundamental Object-Oriented Programming (OOP) concepts.

<h2>‧₊˚ ┊ Overview</h2>
This project models different types of hotel rooms and demonstrates how Java OOP principles can be applied in a practical scenario.

<h2>‧₊˚ ┊ OOP Concepts Demonstrated</h2>
<ul type = "circle">
	<li>𝐄𝐧𝐜𝐚𝐩𝐬𝐮𝐥𝐚𝐭𝐢𝐨𝐧. Protecting object data using access modifiers.</li>
	<li>𝐈𝐧𝐡𝐞𝐫𝐢𝐭𝐚𝐧𝐜𝐞. Creating specialized room classes from a common parent class.</li>
	<li>𝐏𝐨𝐥𝐲𝐦𝐨𝐫𝐩𝐡𝐢𝐬𝐦. Overriding methods to provide different implementations.</li>
	<li>𝐀𝐛𝐬𝐭𝐫𝐚𝐜𝐭𝐢𝐨𝐧. Using abstract classes and methods to define common structures and required behaviors.</li>
	<li>𝐈𝐧𝐭𝐞𝐫𝐟𝐚𝐜𝐞. Defining contracts that can be implemented by different classes.</li>
</ul>

<h2>‧₊˚ ┊ How to Run</h2>
<ol type = "1">
<li>Clone or download this repository.</li>
<li>Open the project folder in your terminal.</li>
<li>Compile the Java source files:</li>

```
javac -d out src/*.java
```
<li>Run the program:</li>

```
java -cp out Main
```
</ol>
